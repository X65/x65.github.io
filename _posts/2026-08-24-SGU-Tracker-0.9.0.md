SGU Tracker 0.9.0 is available for Linux, Windows and the browser.

![SGU Tracker](/media/2026-08-24_SGU-Tracker.png)

This release includes several improvements to everyday editing:

- Clearer instrument, macro and sample editors
- Pattern find/replace, block editing and a pattern manager
- Navigation history and channel mute shortcuts
- Backup restoration
- A stereo analyzer and master VU meters

There is also a Welcome guide for people who have never used a tracker before.
It opens on the first run and can be found again under *INFO → Welcome*.

Supported imports now include `.KT`, `.FZT`, `.A2M`, `.FUR`, `.FTM`, `.SID`,
`.VGM`, `.XM`, `.IT`, `.S3M`, `.AHX`, `.RAD`, `.MOD` and `.MID`.
Songs can be exported as `.SGM` with a 6502 player and an autorun `.XEX`,
or as `.WAV`, `.MID` and plain text.

Linux and Windows downloads are built automatically by CI:  
<https://tracker.x65.zone/latest/>{:target="_blank"}
