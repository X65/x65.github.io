SGU Tracker can play playlists now.

A playlist is a text file with one tune per line - a full URL or a path into one
of the archives, optionally with `&song=N` for a sub-song. The tracker imports
each tune on the fly and plays it on SGU-1, one after another, forever. It
reshuffles every lap, and a song is capped to 10 minutes of playing time unless
you say otherwise with `--seconds`.

There is a *Playlist* band in the File menu with prev/next and info, in both
the GUI and the TUI. The browser version keeps ticking in hidden tabs too,
so you can put it in the background and work.

I've made one for us, with about 245 tunes: C64 SID, Atari POKEY, AdLib, Yamaha
FM, Amiga modules, MIDI. The first hundred came from rankings, then some
Polish composers were added, then I listened to all of it and removed the
crappy ones. The sources are in the `jukebox` directory of the mono repo.

Shuffle and play: <https://tracker.x65.zone/?playlist=https://raw.githubusercontent.com/X65/X65/refs/heads/main/jukebox/play.lst&shuffle&play>{:target="_blank"}

Any playlist reachable over HTTPS works the same way.
